# INTERGROWTH-21st: implemented reference families

`IntergrowthCalculator` is separate from `GrowthChartsCalculator` because gestational age, postmenstrual age, and chronological age are not interchangeable. The implementation uses published regression equations, not the WHO/CDC LMS engine. Install the optional `pedgrowth-data-intergrowth` distribution alongside the core; the core does not export INTERGROWTH-specific classes.

```python
from pedgrowth.data.intergrowth import IntergrowthCalculator

preterm = IntergrowthCalculator('preterm_postnatal')
z = preterm.zscore('weight', 2.0, 35.0, 'M')  # 35 postmenstrual weeks; weight kg

birth = IntergrowthCalculator('very_preterm_birth')
z_birth = birth.zscore('weight', 0.8, 196, 'F')  # 196 gestational days
```

Implemented:

- **Preterm postnatal growth** (27–64 postmenstrual weeks): weight-for-age (kg), length-for-age (cm), head circumference-for-age (cm); weight-for-length (weight kg indexed by length 35–65 cm).
- **Very-preterm size at birth** (168–230 gestational days): birthweight (kg), birth length (cm), head circumference (cm).

No extrapolation is permitted. These standards are not automatically selected in WHO/CDC calculations. Fetal standards and newborn size at birth from 231 days onward require other statistical models and are **not implemented**. In particular, the full newborn size standard uses a skew-t GAMLSS distribution; treating it as LMS would be scientifically incorrect.

## Validation

`tests/test_intergrowth.py` compares outputs against independent INTERGROWTH z-score tables for boys and girls across the supported age/length ranges and seven standard deviations. Small test subsets were transcribed from the published reference tables as distributed in [ropensci/gigs](https://github.com/ropensci/gigs/tree/main/data-raw/tables); they are not generated by the implementation. These checks validate against published rounded values. **New:** an independent
continuous numerical audit executes the original, hash-verified gigs v0.5.2 R
source functions to generate 4,970 additional observations across all seven
concrete tables, both sexes, domain endpoints, randomized coordinates and
extreme measurements. `tests/test_intergrowth_gigs_continuous.py` verifies
those values to within 2e-10 z-score units. The R source is downloaded
separately for the release validation workflow; it is not bundled with or
linked into the Python runtime. The regression coefficients and supported ranges were cross-checked with the documented INTERGROWTH methods in gigs and the original studies. The original R implementation is GPL-3.0; no R code is embedded or executed in this Python library.

References: Villar et al., *Lancet Global Health* 2015, doi:10.1016/S2214-109X(15)00163-1; Villar et al., *Lancet* 2016, doi:10.1016/S0140-6736(16)00384-6. Official tools and charts: https://intergrowth21.tghn.org/standards-tools/.
