# R validation dependencies and their licensing

Reviewed 17 October 2026 against official upstream metadata and the local
installed scientific validation environment. These tools are used only in a
separate GitHub Actions validation job. Their implementations are not Python
runtime dependencies and are not bundled in the pedgrowth distribution.

Exact version and license claims were checked from R package DESCRIPTION
metadata, not inferred from similar software. The first three are installed
in a separate local R library. gigs comes from an original upstream tagged
release, and is executed separately during validation without bundling its
source in the Python runtime.

## Does GPL-3 make pedgrowth a GPL project?

No, not merely because these R packages are used to test it.

- These are independently installed and executed programs; pedgrowth does not
  import R packages, link to them or ship their source implementations.
- The Python library computes its own z-scores. The upstream R code is used
  in CI to compute numerical reference values, which are compared with the
  independently written Python results.
- According to the GNU GPL FAQ, the code license on a program does not
  normally extend to data/results it produces, except if the output itself
  reproduces copyrighted material from that program.
- This reasoning does NOT cover a hypothetical port of GPL-protected R source
  into the Python code; that would need a separate copyright review.

Official GNU GPL FAQ:
https://www.gnu.org/licenses/gpl-faq.en.html#WhatCaseIsOutputGPL

## Important independent rights issue

WHO and INTERGROWTH growth standards and published reference datasets have
their own source permissions. A test result generated by a GPL R tool does
not automatically grant rights to copy or redistribute source datasets or
derived compilations. This is covered by REFERENCE_REUSE_RIGHTS.md.
No WHO/INTERGROWTH permission is represented as granted here.

## Reproducibility and compliance controls

The dedicated .github/workflows/official-validation.yml workflow:

1. Installs R and separate anthro, anthroplus and cdcanthro packages.
2. Executes scripts/verify_r_validation_licenses.R to ensure the exact
   audited versions and declared GPL license strings are unchanged.
3. Runs WHO and CDC comparisons against independently computed values.
4. Fetches the unmodified upstream gigs v0.5.2 release and checks both
   its package license and version as well as the SHA-256 of its three
   reference R source files before computing the INTERGROWTH test results.
5. Keeps R source entirely outside the production wheel; stores only
   reference-result CSVs as CI diagnostic artifacts.

The source distribution contains our project-authored R driver scripts
so the numerical validation can be reproduced; it does not vendor the
upstream R packages. The wheel checker disallows any R source/module files
and the Python runtime declares no R dependency or bridge.

The current workflow installs the CRAN versions available at runtime and
fails closed if one changes; an archived-version installer may eventually
be desirable as CRAN updates. Deliberate fixture regeneration is needed
whenever upstream versions change.

## Independent audit of WHO-embedded LMS reference tables

WHO's official R packages contain the reference coefficients themselves. A direct audit identified 28,228 identical LMS records in 24 WHO tables with no mismatches; 420 extra pedgrowth rows fall outside the R-supported age domain. The package's GPL code license is strong evidence for a possible separately licensed WHO-data route, not a general BSD data grant. See [WHO_R_COEFFICIENT_RIGHTS_AUDIT.md](WHO_R_COEFFICIENT_RIGHTS_AUDIT.md).


## Preservation of the original R software GPL in optional distributions

Each independently built reference-data distribution now records the
original R package license declaration and bundles the complete GNU
GPL v3 text. Its minimal independently authored Python packaging
bootstrap follows the exact original R license SPDX expression
(`GPL-3.0-only` for anthro and cdcanthro, `GPL-3.0-or-later` for
anthroplus and gigs).

Each provider package additionally includes official table/equation links,
the original R package/source links, and an explicit scientific derivation,
usage-methodology and binary-packaging provenance notice. The original
reference datasets are subject to separate rights and are not automatically
GPL-licensed through the R programs. See
`REFERENCE_R_PACKAGE_PROVENANCE.md`.
